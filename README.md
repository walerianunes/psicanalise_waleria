# Site da Waléria Nunes — primeira versão

Esta é uma primeira versão estática do site profissional.

## Antes de publicar
1. Troque `SEUEMAIL@EXEMPLO.COM` pelo seu e-mail.
2. Revise o texto da seção "Sobre mim".
3. Substitua a frase provisória da capa por uma frase autoral ou retire-a.
4. Confirme se o número do WhatsApp está correto.
5. Depois, podemos criar páginas individuais para os textos e ajustar SEO.

## Publicar gratuitamente no GitHub Pages
1. Crie uma conta em https://github.com/
2. Crie um novo repositório público, por exemplo `psicanalise-waleria`.
3. Envie `index.html` e `style.css`.
4. No repositório, abra Settings → Pages.
5. Em "Build and deployment", selecione "Deploy from a branch", escolha `main` e a pasta `/ (root)`.
6. Salve. O GitHub fornecerá um endereço `github.io`.

Não é necessário comprar domínio para usar esta versão.
